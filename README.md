# Onpa

_Onpa is a free and open-source Android app built to help people with hearing needs engage in conversations and stay aware of important sounds._

## ✨ Features

- **Conversation Assistance** – Uses Speech-to-Text (STT) and Text-to-Speech (TTS) so users can talk with others who don’t know sign language.  
- **Sound Detection** – Identifies important environmental sounds (like sirens) and notifies the user.  
- **Quick Phrases** – Save and reuse common responses for faster conversations.  
- **Offline Friendly** – Core functionality works without internet.
