# Contributing to Onpa

Thank you for considering contributing to **Onpa**! 🎉  
We welcome contributions of all kinds — bug fixes, documentation improvements, new features, or design ideas.  

---

## 🛠 How to Contribute

1. **Fork the repository**  
   - On the top right of this repository page, click the **Fork** button to create your own copy of the project.

2. **Open the project in Android Studio**  
   - In Android Studio, go to **File > New > Project from Version Control**.  
   - Paste the link to your forked repository and open it.  

3. **Create a new branch**  
   - In Android Studio, use the **Git branch menu (bottom-right corner)** to create a new branch for your changes.  
   - Name it something descriptive (e.g., `feature-dark-mode` or `fix-login-bug`).  

4. **Make your changes**  
   - Implement your feature, fix the bug, or update documentation.  
   - Test your changes by running the app in the emulator or on a device.  

5. **Commit and push**  
   - Use **Android Studio’s Git panel** to commit your changes with a clear message.  
   - Push your branch to your forked repository on GitHub.  

6. **Open a Pull Request**  
   - Go to your fork on GitHub.  
   - You will see a **“Compare & pull request”** button. Click it.  
   - Fill in the details of your changes, and submit the pull request for review.  

---

## 📌 Guidelines

- For **major changes**, please **open an issue** first to discuss your idea.  
- Be respectful and constructive in all discussions.  
- Keep commits **clear and focused** (e.g., “Fix: crash when saving settings”).  

---

## 🧑‍💻 Coding Style

- Follow **Kotlin best practices**.  
- Use **Android Studio’s auto-formatting** (`Code > Reformat Code`) before committing.  
- Keep functions and classes small, clear, and reusable.  

---

## 🧪 Testing

- Make sure the app builds and runs before opening a pull request.  
- If fixing a bug, explain how to reproduce it in your PR description.  
- If adding a feature, describe how it can be tested.  

---

## 🙌 Recognition

All contributors will be credited in this project. Thank you for helping improve **Onpa** 💙
